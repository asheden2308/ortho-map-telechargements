# Données publiques d'Ortho-Map
Historique des arrivées et départs d'orthophonistes en France, calculé chaque nuit à partir de
l'Annuaire Santé (données publiques), pseudonymisé : aucun nom ni numéro en clair. Utilisé par l'application
Ortho-Map à sa première installation. opposition.json : orthophonistes qui ont demandé à ne pas apparaître.
